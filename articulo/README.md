# Artículo asociado

Esta carpeta reserva la ubicación del artículo asociado al laboratorio.

Cuando el PDF esté disponible:

1. Subí el archivo con el nombre `articulo-pendulo.pdf` dentro de esta carpeta.
2. Editá el enlace `article-download` de `index.html`.
3. Quitá la clase `disabled`, los atributos `aria-disabled` y `tabindex`.
4. Agregá el atributo `download` y cambiá el texto por `Descargar artículo`.

La ruta final será:

```text
articulo/articulo-pendulo.pdf
```
