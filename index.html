Información numérica

Integración reproducible

Pyodide 314.0.4 ejecuta Python 3.14.2 dentro del navegador, con NumPy 2.4.3 y SciPy 1.18.0. Todas las simulaciones usan solve_ivp, RK45, rtol = 1×10⁻⁹, atol = 1×10⁻¹¹ y 6000 puntos uniformes.

Cómo utilizar el laboratorio

Lectura de las gráficas

Elegí un modelo, aplicá un caso predeterminado o modificá sus controles y ejecutá la simulación. θ se expresa en radianes; τ representa el tiempo adimensional; dθ/dτ representa la velocidad angular adimensional. Los parámetros carecen de unidades.
