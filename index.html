Simulación numérica de modelos lineales y no lineales del péndulo plano

Laboratorio interactivo para comparar la evolución temporal θ(τ) y los retratos de fase (θ, dθ/dτ) de seis modelos adimensionales. El navegador ejecuta la integración numérica con Python.

Preparando Python, NumPy y SciPy. La primera carga puede demorar.

Metodología numérica

Configuración de la integración

El laboratorio ejecuta Python 3.14.2 en el navegador mediante Pyodide 314.0.4, NumPy 2.4.3 y SciPy 1.18.0. La función solve_ivp integra cada modelo con el método RK45, una tolerancia relativa de rtol = 1×10⁻⁹ y una tolerancia absoluta de atol = 1×10⁻¹¹. El programa evalúa cada solución en 6000 valores uniformes del tiempo adimensional.

Procedimiento de exploración

Uso e interpretación de las gráficas

Seleccioná un modelo y un caso predeterminado, o modificá los parámetros y las condiciones iniciales. Ejecutá la simulación y compará la evolución temporal con el retrato de fase. La variable θ representa el desplazamiento angular en radianes, τ corresponde al tiempo adimensional y dθ/dτ representa la velocidad angular adimensional. Los parámetros de cada modelo se expresan en forma adimensional.
